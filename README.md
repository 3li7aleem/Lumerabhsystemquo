# LUMERA Manufacturing Studio

Arabic-language static manufacturing and pricing prototype for LUMERA, featuring 150 catalog models, cutting lists, material takeoffs, and print-to-PDF reports.

## Usage
Open `index.html` in a browser or publish this repository with GitHub Pages (Settings > Pages > Deploy from branch > main / root).

## Important
- Product dimensions and cutting estimates are preliminary unless explicitly marked as referenced and verified.
- Prices are illustrative and must be updated before real quotes.
- The website is static and currently **does not offer authenticated access controls**. Since the repository is public, all code and calculation defaults are publicly accessible.
- Verify structural requirements, cut lists, and workshop specifications before production.

This repository was created from the original LUMERA_Ready_To_Publish.zip package.
